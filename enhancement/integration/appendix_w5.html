付録 A ── AR-DB と本書の参照系譜

書物の背後には、書物を可能にした書物群がある。
本書の背後には、それを可能にした 46 のデータベースがある。

― 統合ライター W5・編者付記、2026年5月

本書は単独の構想物ではない。NPO法人ミラツク／esse-sense が 2024 年以降に構築してきた 60 を超えるデータベース群──総称してミラツク DB エコシステム──を、Agent Registry DB (AR-DB v1.0、358 records / 1,490 relations / 564 db_references) を媒介として横断参照しながら書かれた。AR-DB は、ミラツク／esse-sense エコシステムで稼働する全エージェント・コマンド・スキル・ルールを集約し、各エージェントがどの DB を参照し、どの DB が誰に参照されているかを可視化する自己観察基盤である。

この付録の目的は、本書の各章がどの DB から何を引いたかを開示することにある。読者は本書を読み終えた後、ここに掲げられた DB 名と SQLite クエリ例を手がかりに、自分自身で一次データに触れ、自分の「次の問い」を立てることができる。教科書とは、読者を独立した探究者へと送り出すための地図でなければならない、という著者の信念がここに表れている。

A-3. SQLite クエリ例 ── 再現性のために

読者が本書の主張を検証する、あるいは自分の問いから DB を引き直すための、最頻出 5 つのクエリパタンを以下に掲げる。

クエリ 1 — 任意の DB について、誰がそれを参照しているか

-- AR-DB: ある DB を参照しているエージェント一覧
sqlite3 ~/projects/research/agent-registry-db/data/agent_registry.db \
  "SELECT a.name, a.tier, a.domain FROM db_references dr
   JOIN agents a ON a.id = dr.agent_id
   WHERE dr.db_name = 'ftt-db'
   ORDER BY a.tier, a.name;"

クエリ 2 — FTT-DB から特定領域の論文系譜を抽出

-- FTT v2: NEUROMORPHIC 領域の milestone を年代順
sqlite3 ~/projects/research/future-tech-trends-db/v2/data/ftt_v2.db \
  "SELECT year, milestone_title, organization, doi_or_url
   FROM technology_milestones
   WHERE domain_id IN (SELECT id FROM domains WHERE code='NEUROMORPHIC')
   ORDER BY year;"

クエリ 3 — PHAI-DB から 5 系統合流の関係を引く

-- PHAI: 5 系統の合流関係を一覧
sqlite3 ~/projects/research/physical-ai-db/data/phai.db \
  "SELECT s1.name AS from_stream, s2.name AS to_stream, sr.relation_type, sr.notes
   FROM phai_stream_relations sr
   JOIN phai_streams s1 ON s1.id = sr.stream_from
   JOIN phai_streams s2 ON s2.id = sr.stream_to;"

クエリ 4 — Signal-DB から特定 Phase 進入シグナルを取得

-- Signal: メインストリーム化年数推定が 2030-2040 のシグナル
sqlite3 ~/projects/research/pestle-signal-db/data/signal.db \
  "SELECT signal_id, signal_title, signal_type, mainstream_year_estimate, source_url
   FROM signals
   WHERE mainstream_year_estimate BETWEEN 2030 AND 2040
   ORDER BY mainstream_year_estimate;"

クエリ 5 — CLA-DB から特定時代の四層構造を引く

-- CLA: 2020 年代の litany / system / worldview / myth 四層
sqlite3 ~/projects/research/cla-db/data/cla.db \
  "SELECT layer, content, source_type
   FROM cla_records
   WHERE year_range_start >= 2020
   ORDER BY layer, year_range_start;"

A-6. 注記 ── Great Figures DB の限界と人物典拠の代替経路

重要な限界の開示: Great Figures DB (9,178 人物) は人物典拠の主源として期待されたが、Physical AI 系譜の中核研究者 (Hinton, LeCun, Bengio, Sutton, Brooks, 浅田稔, 川人光男, 松尾豊 等) のうち実在 row として収録されているのは Alan Turing 1 名のみであった (収録率約 1%)。本書の人物典拠は AR-DB を経由して FTT-DB v2.0 の people テーブル (185,767 row、うち curated 60+ 名) および PHAI-DB の concept_relations、補論的に ai-development DB の著者リンクを主源とした。詳細は ~/projects/research/physical-ai-2100/enhancement/db-evidence/gf_evidence.md に検証ログを残している。今後 Great Figures DB を collection_wave='physical_ai_2026_05_18' で拡張する Wave が企画されれば、教科書改訂と DB 拡張が同時達成される。
